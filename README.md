# 📖 About Build Wise

Build Wise is a modern construction project management application designed for:

- 👨‍💼 Contractors
- 🏠 House Owners
- 👷 Site Engineers
- 🏗️ Builders
- 🎨 Interior Designers

The app helps users organize construction projects from start to finish while keeping complete control over budgets, expenses, materials, and progress.

# 💾 Data Backup & Restore

Build Wise supports complete offline backups.

### Backup Includes

- Projects
- Expenses
- Materials
- Stages
- Photos
- Categories
- Settings

### Backup Format

```text
buildwise_backup.zip
```

Structure:

```text
buildwise_backup.zip
│
├── data.json
│
└── photos/
```
