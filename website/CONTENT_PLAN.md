## FAQ

1. **How does Build Wise work?** Create a project, set a budget, then log
   expenses, materials, stages, and photos. The dashboard shows budget vs.
   spent and overall progress in real time.
2. **Does Build Wise require internet?** No. Build Wise is offline-first —
   every feature works without a connection. No account or sign-in needed.
3. **Can I back up my project?** Yes. Export any project (or all projects) to a
   single `.zip` backup file containing your data and photos.
4. **Can I restore data on another device?** Yes. Move the backup file to the
   other device and import it — as a new project or to replace an existing one.
5. **Can I track construction expenses?** Yes. Record amount, category, vendor,
   date, payment type, and link each expense to a construction stage.
6. **Is my data private?** Your projects, photos, and records are stored only on
   your device. Build Wise does not upload them anywhere.
